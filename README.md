   # github-final-project

   ## Simple Interest Calculator
   A Bash script that calculates simple interest from a principal amount,
   a rate of interest, and a time period. It is hosted here as the first
   step in migrating the team's code from SVN to Git.

   **Formula:** Simple Interest = (Principal × Rate × Time) / 100

   ## Usage
```bash
   chmod +x simple-interest.sh
   ./simple-interest.sh
```
